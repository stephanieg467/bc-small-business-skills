# Report Pack

Her regular numbers plus a few lines of context, delivered as **one briefing**
for one business. Read-only.

Read first: `references/common/ground-rules.md`, `references/common/business-profiles.md`.

## Step 1: The reports (report-builder)

Run `report-builder` for each saved report in this pack (from the project's
"Saved reports" file). A new pack gets its spec confirmed once; a saved pack runs
with no questions. Ask for all the needed exports in **one checklist** across all
reports in the pack. Many reports share the same files, so don't ask twice.

## Step 2: The context snapshot

From the same files (plus the bank balance if she gives it), write 3 to 5 lines:
- **Cash**: balance and date (or "no balance given")
- **Sales trend**: this period vs comparison, one line
- **Due soon**: bills, GST/PST remittance, CRA source deductions or payroll in the
  next 14 days, if the files show them
- **AR** (Fun Water Pools): total over 30 days
- **One thing that needs attention**: the single most important item

This is context, not a second report. Don't ask for extra files just for the
snapshot; leave a line out and say what would fill it.

## Step 3: Deliver as one thing

One message: the pack summary, then the snapshot, then the workbook (all reports'
tabs in one workbook, with the Summary tab first). If she wants it as a doc for
her husband or the accountant, make one doc with the same content.

## Step 4: Cadence, honestly

After a run she found useful, offer once: *"Want this every month?"* Then follow
`ground-rules.md` rule 8: set up a scheduled task if her Claude has them (the run
will still need her to upload the exports, so say that), or tell her the phrase
to say each month. Never claim it's scheduled if it isn't.

## Step 5: Thin runs still ship

If a file is missing, that metric is "n/a (no <file>)" and the pack still goes out.
Never skip the whole pack because one file is missing.

## After

One next step: "cash forecast" if cash looked tight; "who owes me money" if AR is
up; "build me a report" to change what the pack tracks.
