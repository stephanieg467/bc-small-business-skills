# Output template

## Chat summary

```
<Report name>, <Business>, <period>
Sources: <reports used>   (provisional if the period isn't closed)

1. <Headline metric>: CAD X, <+/−Y%> vs <comparison>.
2. <Finding 2 with number and comparison>
3. <Finding 3: the outlier, named>

Watch: <one thing to keep an eye on>
```

Rules: numbers first, every number with its comparison, three findings maximum,
plain words ("gross margin (what's left of sales after the cost of the product)").

## Workbook

1. **Summary**: metric | this period | comparison | change | change %
2. One tab per metric group (e.g. "By category"), sorted by size, with a total row
3. **Data**: the raw rows used, unedited, with the source file name in a column
Money as `CAD #,##0.00`, percentages to one decimal place.
