# Capturing the routine

Ask these one at a time, only the ones not already answered.

1. **What starts it?** A day ("every Friday"), an event ("when the wholesale invoice
   arrives"), or a question she asks herself ("am I low on pre-rolls?").
2. **Which business?** One, the other, or both (separately).
3. **What goes in?** Which Cova or Sage 50 report (and the date range), which
   emails, which spreadsheet. Get the exact report names she sees.
4. **Walk me through it.** Each step as she does it now, including the boring ones.
5. **What decisions do you make along the way?** These become questions or rules.
6. **What comes out, and where does it go?** A number, a sheet, an email to
   someone, a note for Sage 50.
7. **What has gone wrong before?** These become "Never" lines.
8. **How often, and how long does it take you now?** (Confirms it's worth a skill.)

## Is it worth a skill?

Yes if it repeats at least monthly, has the same steps each time, and takes her
more than about 10 minutes. No if it's a one-off, or if an existing skill already
does it (check the list in `smb-onboard`). Then just use that skill.
Building a skill that isn't needed costs trust when it misfires.
