# Metric → source

| Metric | Cannabis Cottage | Fun Water Pools |
|---|---|---|
| Revenue / net sales | Cova Sales Summary (pre-tax), or Sage 50 Income Statement | Sage 50 Income Statement |
| Sales by product / category | Cova sales by product or category | Sage 50 sales accounts, Sales by Item (if items used) |
| Gross margin | Cova (if cost set up) or Sage 50 Income Statement (sales − COGS) | Sage 50 Income Statement |
| Discounts | Cova Sales Summary | Sage 50 (if discounts recorded) |
| Transactions / average sale | Cova Sales Summary | n.a. (invoices: Sage 50 Sales Journal count) |
| Inventory value / shrink | Cova Inventory On Hand / Inventory Adjustment | Sage 50 inventory reports, if inventory is tracked |
| AR aging | usually not relevant | Sage 50 Customer Aged Detail |
| AP aging | Sage 50 Vendor Aged Detail | Sage 50 Vendor Aged Detail |
| Labour cost | Sage 50 Income Statement (wage accounts) or Payroll Journal totals | same |
| Cash | Bank statement or Sage 50 Balance Sheet | same |
| Sales tax collected | Cova Sales Summary + Sage 50 tax accounts | Sage 50 tax accounts / tax report |

Menu paths: `references/common/sage50-canada.md` and `references/common/cova.md`.
No connector exists for Sage 50 or Cova, so every run uses uploaded exports.
